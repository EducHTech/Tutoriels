# 00 — Installation des outils

> **Durée estimée :** 20 à 40 min (selon ce que tu as déjà)
> **À faire :** une seule fois. Si tout est déjà installé, passe directement aux [bases communes](../01-bases-communes/01-introduction-projet.md).

---

## Check-list rapide

Avant de commencer, vérifie ce que tu as déjà :

Ouvre le terminal VSCode (ou un terminal quelconque) et tape ces commandes une par une.

```bash
python --version
```
```bash
git --version
```

- Si tu vois un numéro de version → c'est déjà installé ✅
- Si tu vois une erreur → il faut l'installer ❌
