# 04 — Extension Python dans VSCode

> **Durée estimée :** 5 min
> **Prérequis :** [Python installé](./03-installer-python.md)
> **Objectif :** installer l'extension Python pour avoir la coloration et l'autocomplétion

---

## C'est quoi une extension VSCode ?

VSCode peut être enrichi avec des **extensions** : ce sont de petits ajouts qui améliorent le logiciel.

L'extension Python permet :
- la **coloration du code** (les mots-clés changent de couleur)
- l'**autocomplétion** (des suggestions apparaissent en tapant)
- de **lancer le script** directement depuis VSCode

---

## Installation de l'extension Python

### 1. Ouvrir le panneau Extensions

Dans VSCode, clique sur l'icône Extensions dans la barre latérale gauche, ou utilise le raccourci :

```
Ctrl + Shift + X
```

### 2. Chercher l'extension

Dans la barre de recherche en haut, tape :

```
Python
```

### 3. Installer la bonne extension

Tu vas voir plusieurs résultats. Installe celle qui s'appelle **Python** et dont l'auteur est **Microsoft**.

> [!IMPORTANT]
> Vérifie bien que l'auteur est **Microsoft**. Il existe des extensions qui ont des noms similaires mais qui viennent d'autres personnes.

Clique sur **Install**.

---

## Vérifier l'installation

1. Crée un nouveau fichier : `Fichier → Nouveau fichier`, nomme-le `test.py`
2. Tape `print(` dans ce fichier
3. Tu dois voir apparaître des suggestions d'autocomplétion

Si les suggestions apparaissent → l'extension fonctionne ✅

---

## Cases à cocher

- [ ] L'extension Python (Microsoft) est installée
- [ ] La coloration du code fonctionne dans un fichier `.py`

---

> [!TIP]
> Pendant le TP, si VSCode te demande "Sélectionner un interpréteur Python", clique sur la version Python 3.x que tu as installée.
