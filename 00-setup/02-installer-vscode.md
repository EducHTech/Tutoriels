# 02 — Installer VSCode

> **Durée estimée :** 10 min
> **Prérequis :** [C'est quoi le terminal ?](./01-c-est-quoi-le-terminal.md)
> **Objectif :** avoir VSCode installé et ouvert

---

## C'est quoi VSCode ?

VSCode (Visual Studio Code) est un **éditeur de code**. C'est le logiciel dans lequel tu vas écrire tes programmes Python et consulter ces tutoriels.

Il est gratuit, fabriqué par Microsoft, et utilisé par des millions de développeurs dans le monde.

> [!NOTE]
> VSCode ≠ Visual Studio. Ce sont deux logiciels différents. On utilise **Visual Studio Code** (le léger, gratuit).

---

## Déjà installé ?

Vérifie si VSCode est déjà sur ton ordinateur :

1. Appuie sur la touche **Windows** (ou clique sur le menu Démarrer)
2. Tape `code`
3. Si VSCode s'ouvre → il est déjà installé ✅, passe à [l'étape suivante](./03-installer-python.md)

---

## Installation

### 1. Télécharger VSCode

Va sur : [https://code.visualstudio.com/](https://code.visualstudio.com/)

Clique sur le gros bouton bleu **Download for Windows**.

### 2. Lancer l'installeur

Double-clique sur le fichier `.exe` téléchargé.

Pendant l'installation, **coche ces cases** (importantes !) :

```
✅ Ajouter l'action "Ouvrir avec Code" au menu contextuel de l'Explorateur Windows
✅ Ajouter à PATH
```

### 3. Terminer l'installation

Clique sur **Installer** puis **Terminer**.

---

## Vérifier que ça marche

1. Ouvre VSCode
2. Ouvre le terminal intégré : `Ctrl + ù`
3. Tu dois voir une fenêtre noire en bas avec un curseur qui clignote

---

## Cases à cocher

- [ ] VSCode est installé
- [ ] Je peux l'ouvrir
- [ ] J'ai ouvert le terminal avec `Ctrl + ù`

---

> [!WARNING]
> Si le terminal ne s'ouvre pas avec `Ctrl + ù`, essaie via le menu : **Affichage → Terminal**
