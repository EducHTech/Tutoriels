# Groupe B — Robot ESP32

> **Pour qui :** Groupe B uniquement
> **Prérequis :** [Bases communes terminées](../01-bases-communes/README.md) + [Arduino IDE installé](../00-setup/06-installer-arduino-ide-esp32.md)
